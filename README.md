# LeetCode Problems

A curated collection of **LeetCode problem solutions** focused on building strong fundamentals in **data structures and algorithms** through consistent practice and clean implementations.

This repository serves as both a **learning log** and a **long-term reference** for common problem-solving patterns, edge cases, and optimizations.

---

## 📌 About

This repository contains solutions to selected LeetCode problems solved over time, with an emphasis on:

- Clear and readable code  
- Understanding core concepts rather than memorization  
- Identifying reusable patterns (e.g., two pointers, sliding window, recursion, DP)  
- Writing solutions that balance correctness and efficiency  

Problems are added incrementally as part of ongoing practice.
